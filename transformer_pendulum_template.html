1. 为什么用 Transformer 控制倒立摆？

传统做法（如 LQR）需要精确的物理建模与线性化，控制器是一个固定增益矩阵 u = −K·z。而 Transformer 把控制问题重新表述为序列到动作的映射：输入最近 T 步的状态序列，直接输出控制力。它的核心优势在于多头自注意力——控制器能自动学会"哪些历史状态对当前决策更重要"，无需人工设计特征。

2. 训练方法：模仿学习（Behavior Cloning）

用一个已成熟的 LQR 控制器作为"专家教师"，让它在各种初始状态、随机扰动下控制倒立摆，收集 (状态序列 → 控制力) 样本，再用均方误差监督学习训练 Transformer 逼近专家策略：

Loss = 𝔼[ ( u_Transformer(X) − u_LQR(z_t) )² ]
// X = 最近 T 步状态序列，z_t = 当前状态，u_LQR = 专家控制力

3. 网络结构

输入 X: (T=8, 4) 状态序列
↓ 线性嵌入 4→32 + 正弦位置编码
多头自注意力 (4 头, d_k=8) + 残差 + LayerNorm
↓
前馈网络 FFN (32→64→32) + 残差 + LayerNorm
↓ 取最后一个位置的输出
线性输出头 (32→1) → 控制力 u

4. 多头自注意力

每个头独立地把状态序列投影到 Query/Key/Value，计算注意力分数并加权聚合。不同头关注不同模式（位置、角度、速度等）。注意力权重会实时可视化在上方热力图中。

Attention(Q,K,V) = softmax( Q·Kᵀ / √d_k ) · V

算法 1 · Transformer 前向推理（每步控制）

function transformer_control(X, params):
    // X: (T, 4) 状态序列
    H ← X @ We + be            // 线性嵌入
    H ← H + PE                 // 正弦位置编码
    Q, K, V ← H @ W{q,k,v} + b    // 投影
    for each head h:
        scores_h ← Q_h @ K_hᵀ / √d_k
        attn_h   ← softmax(scores_h)
        ctx_h    ← attn_h @ V_h
    ctx ← concat(ctx_h) @ Wo + bo
    H ← LayerNorm(H + ctx)     // 残差
    H ← LayerNorm(H + ReLU(H@W1+b1)@W2+b2)  // FFN
    u ← H[T-1] @ Wo_final + b_final   // 取末位置输出
    return u
